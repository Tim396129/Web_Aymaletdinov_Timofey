# Химия вокруг нас

Небольшой сайт рассказывающий про элементы из таблицы Менделеева.

## Что внутри проекта
1. index1.html - первая страница сайта показывающий некоторые элемты из таблицы Менделеева,
2. elements.html - вторая страница сайта показываюзий карточки элементов из таблицы Менделеева.

## Как запустить
1. Скачать файл проекта к себе на ПК,
2. Открыть скаченный файл. Затем нажать два раза на файл "index1.html",
3. Откроется вам нужный сайт. Чтобы переключатся между страницами пролистните вниз.
